内贸记录来自用户提供的《华北已走访11-11.xlsx》。处理时按企业名称、城市和地址归并重复走访，保留走访次数、最近走访日期、走访结果、物流模式、箱型、流向、船公司、车队、货类、产能和工厂情况。无法识别真实企业名称的地图点位（公厕、饭店、加油站等）未写入客户名单。

## 看板功能

- 全部、内贸走访、外贸线索、内外贸兼有四种业务模式筛选
- 区域、城市、客户分类、核验状态、可信度、地址状态和关键词联动筛选
- 地图与企业名单联动，点击企业查看详情
- 详情中可编辑企业、业务模式、地址、坐标、物流和走访字段
- 编辑数据自动缓存到当前浏览器 localStorage
- 支持 Excel（XLSX/XLS）和 CSV 模板批量导入
- 支持导出当前完整数据 XLSX
- 可按模板新增企业，也可在地图上点选坐标

## 导入模板

模板文件：

- templates/华北客户新增导入模板_2026-11-11.xlsx

必填字段：

- 业务模式
- 企业名称
- 城市
- 详细地址

经纬度可留空。留空时系统按同城/同区县现有企业点位近似落点，并明确标注为行政区近似。

## 数据隐私

- 公共 GitHub Pages 不包含走访表中的联系人和联系方式
- 联系人、联系方式仅保存在导入者浏览器缓存或用户导出的本地 XLSX 中
- 公开发布前不要把含内部联系方式的原始走访表上传到公开仓库

## 本地使用

在项目目录启动静态服务：

    python -m http.server 8777

打开 http://127.0.0.1:8777/index.html。

## GitHub Pages

将本目录中的网页文件、assets、data 和 templates 发布到仓库根目录。GitHub Pages 在线版是静态页面，访问者的编辑和新增只会保存在各自浏览器中，不会写回公共数据。

## 数据限制

- 内贸经纬度为同城/同区县近似落点，不代表工厂门牌
- 原始走访表存在少量地址型点位，已进行名称清洗；仍建议在客户跟进前用企业官网、地图和电话复核
- “制造企业身份”不等同于“已有出口订单”或“外贸能力已核验”
